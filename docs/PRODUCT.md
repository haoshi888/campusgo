# CampusGo 产品说明

## 1. 问题与机会

大学生二手交易目前主要依赖微信群和闲鱼：

- 微信群信息碎片化，商品很快被聊天淹没，无法搜索和筛选。
- 闲鱼用户地理距离远，无法有效匹配“同校、宿舍楼、教学楼”这种极小半径交易。
- 学生之间缺少统一的校园身份展示，首次交易信任成本高。
- 毕业生离校时间有限，商品供给集中爆发，需要一个高效率的短周期交易工具。

CampusGo 的机会是同时降低三类成本：发现成本、信任成本、交付成本。

## 2. 产品定位

通过校园身份认证和校园地理匹配，帮助大学生快速找到可信赖的附近闲置商品，实现低成本、高效率交易。

核心价值：附近的学生，交易附近的闲置。

## 3. 用户与冷启动策略

第一阶段核心用户是毕业生卖家。校园二手交易的核心瓶颈不是买家需求，而是有效供给。大四毕业前 30 天集中处理小冰箱、台灯、自行车、教材、显示器等物品，毕业生对成交价格敏感度低于时间成本，愿意接受校园内快速交付。

因此产品早期的核心任务是让毕业生快速发布完整商品信息，并把商品推荐给同校、500m 内的潜在买家。第二阶段面向新生与低年级学生，重点需求是低价生活用品、教材和学习设备。

## 4. 核心用户流程

买家路径：首页发现 → 搜索筛选 → 商品详情 → 咨询卖家 → 当面验货 → 确认成交 → 评价。

卖家路径：进入发布 → 填写商品信息 → 选择交易地点和时间 → 预览确认 → 发布成功 → 收到咨询 → 完成交易。

## 5. 指标口径

| 指标 | 口径 |
| --- | --- |
| DAU | 当日产生任意有效行为事件的去重用户数 |
| 商品发布数量 | 指定周期内 `publish_product` 事件数 |
| 商品浏览量 | `click_product` 商品点击事件数 |
| 聊天次数 | `click_chat` 联系卖家事件数 |
| 成交数量 | `complete_trade` 事件数 |
| 点击率 | 商品点击 / 商品曝光 |
| 咨询率 | 发起咨询 / 商品点击 |
| 成交率 | 完成成交 / 发起咨询 |
| 整体转化率 | 完成成交 / 商品曝光 |

## 6. 后续迭代建议

1. 供给增长：毕业季倒计时、批量发布、宿舍楼供给地图。
2. 信任建设：校园邮箱/学信网认证、违规举报、争议记录。
3. 匹配效率：基于浏览和收藏行为做同校推荐与降价提醒。
4. 成交效率：约定时间双向确认、交易二维码、到点提醒。
5. 商业化测试：校园横幅广告、搬家公司合作、毕业生打包服务。
